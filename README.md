# Big Data Deep Learning Module - Student version  
See Studium for instructions on how to log in to your pods.

### Clone this repo to your pod  
See the notebook section below. You can (and will) open terminals in your pod (e.g., during cloning), but we will primarily work in notebooks.

Ask a teacher if you do not know how to clone a repository.

## Notebook  
Work in the provided notebooks; no need to copy code into new ones.  
Only work in one notebook at a time due to memory limitations.  
Make sure to work in the notebook from only one computer, or the automatic saving system may cause issues.

## Unzip the data before you start the lab  
To unzip, use the command `tar -xvf`, which you used in the storage lab.

## Assignments  
The mandatory assignment must be passed in order to pass the course. Follow the instructions in the assignment notebook and any instructions given in Studium.

Use the discussion forum in Studium for questions, or ask during lab or assignment sessions.
