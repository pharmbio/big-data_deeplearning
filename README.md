## Notebook
Work in the provided notebooks, no need to copy code to new ones.
Only work in one notebook at a time due to limitaions in memory. 
Make sure to work in the notebook from one computer or the automatic saving system will cause you great grief.

## Unzip the data before you start the lab
To unzip use the command `tar -xvf` which you used in the storage lab.
